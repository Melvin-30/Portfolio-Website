# Melvin Dominic Fernandes — Developer Portfolio

A responsive, single-page developer & gamer portfolio website built with a modern dark aesthetic, purple/indigo accent palette, interactive glassmorphism navigation, and an organized credentials showcase.

![Portfolio Preview Banner](https://capsule-render.vercel.app/api?type=waving&color=gradient&customColorList=6,11,20&height=150&section=header&text=Melvin%20Dominic%20Fernandes&fontSize=38&fontColor=A970FF&animation=twinkling)

---

## 🚀 Key Features

- **⚡ Developer & Gamer Aesthetic:** Sleek dark background (`#06040a`) with violet/indigo glows, terminal panes, and code editor windows.
- **📱 Responsive Glassmorphism Navbar:** Fixed header with blur backdrop, auto-scrolling progress bar, active section indicators, and mobile drawer menu.
- **📜 Verified Credentials Showcase:** Interactive category filter bar displaying 20+ verified certificates across Microsoft, IBM, Deloitte, Coursera, Intel, Infosys Springboard, STP Computers, WhiteHat Jr, and Udemy with direct local PDF viewer links and official verification URLs.
- **💻 Interactive Code & Terminal Components:** Animated typing effect for role titles, interactive YAML profile inspector pane, and one-click copy to clipboard buttons for code blocks.
- **📊 GitHub Live Stats Integration:** Integrated GitHub streak stats, top languages badge, profile trophies, and contribution activity graph.

---

## 🛠️ Tech Stack

- **Structure:** Semantic HTML5
- **Styling:** Vanilla CSS3 (Custom Properties, Flexbox, CSS Grid, Glassmorphism & Keyframe Animations)
- **Logic:** Vanilla JavaScript (ES6+)
- **Icons:** [Lucide Icons](https://lucide.dev)
- **Fonts:** JetBrains Mono & Plus Jakarta Sans via Google Fonts

## 💻 Running Locally

No build tools or node packages required. Simply open `index.html` in any web browser:

```bash
# Clone the repository
git clone https://github.com/Melvin-30/Portfolio-Website.git

# Navigate into the project folder
cd Portfolio-Website

# Open index.html in your browser (or use Live Server in VS Code)
```
